# עמדת טעינת רב־קו — גרסה חדשה

יישום WinForms חדש ונפרד, שאינו משתמש ב-MainForm, AppSettings או במנגנון החסימות של הגרסה הקודמת.

## שני שירותים נפרדים
- HopOn: `https://hopon.co.il/read`
- רב־קו אונליין: `https://ravkavonline.co.il/he/store/connect`

לכל שירות חלון WebView2 ופרופיל משתמש נפרדים, לרבות Cookies, אחסון מקומי והתחברות.

## מדיניות ניווט חדשה
- רשימה שחורה חדשה וממוקדת לנתיבי מידע שאינם חלק מהטעינה ב-HopOn.
- כל דפי HTTPS תקינים של ספק התשלום, אימות CAPTCHA, אימות בנקאי ותהליך הטעינה מותרים, גם כאשר הם בדומיין חיצוני.
- אין חסימת משאבי רשת גורפת, אין הזרקת JavaScript לחסימת טפסים/היסטוריה, ואין נעילה לעמוד כניסה יחיד ברב־קו אונליין.
- חלונות HTTPS נפתחים כחלונות WebView2 אמיתיים כדי לשמר window.opener ו-postMessage.
- פרוטוקול קורא הכרטיסים מותר גם כשהוא מופעל מתוך iframe, אך ההפעלה דורשת אישור משתמש ובדיקת מקור האתר.
- HTTP, כתובות עם פרטי משתמש ופורט לא סטנדרטי, ופרוטוקולים חיצוניים לא מוכרים נחסמים.
- הורדות אינן מבוטלות בשקט.

## נתונים ואבחון
יומני האבחון נשמרים ב:
`%LOCALAPPDATA%\RavKavKioskV2\Logs\kiosk-v2.log`

פרופילי WebView2 נשמרים ב:
`%LOCALAPPDATA%\RavKavKioskV2\WebView2\HopOn`
ו-`%LOCALAPPDATA%\RavKavKioskV2\WebView2\RavKavOnline`

## מגבלה
בדיקת בנייה/התקנה אינה יכולה לאמת קורא USB, תוכנת קורא חיצונית או חיוב אמיתי. יש לבדוק את אלה במחשב העמדה עם כרטיס וקורא בפועל.
