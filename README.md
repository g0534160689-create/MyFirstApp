# טעינת רב־קו — אפליקציית Windows

אפליקציית Windows במסך ייעודי, שנפתחת ישירות בעמוד הרשמי של Rav-Kav Online ומגבילה ניווט אינטרנטי לכתובות HTTPS שאושרו מראש.

## מצב הפרויקט

זהו שלד פיתוח ראשוני, **לא גרסה מוכנה לשימוש או לפרסום למשתמשי קצה**. לפני שמכריזים על תמיכה מלאה יש לבצע בדיקות עם קורא רב־קו אמיתי, תוכנת הקורא הרשמית, תהליך התשלום והאתר העדכני.

## מה כבר קיים

- ממשק WinForms ללא שורת כתובת או לשוניות.
- פתיחה ישירה בכתובת הרשמית: https://ravkavonline.co.il/he/store/welcome
- חסימת ניווט HTTPS למארחים שאינם ברשימת האישור.
- חסימת חלונות קופצים, הורדות, תפריטי הקשר וכלי פיתוח.
- חסימת הרשאות אתר שאינן נדרשות.
- טיפול נפרד בפרוטוקולים חיצוניים, כדי שניתן יהיה לאשר את פרוטוקול תוכנת הקורא לאחר זיהויו.

## דרישות להשלמת התמיכה בקורא ובתשלום

1. לזהות בבדיקה את פרוטוקול ההפעלה המדויק של תוכנת קורא הכרטיסים הרשמית, ורק אותו להוסיף ל-`AllowedExternalSchemes`.
2. לבצע תהליך טעינה מלא בסביבת בדיקה ולתעד את כל שמות המארחים שאליהם האתר מפנה, כולל ספק התשלום. להוסיף ל-`AllowedHttpsHosts` רק מארחים שאומתו כחלק הכרחי מהתהליך.
3. לבדוק שהאתר ותוכנת הקורא תומכים בפועל ב-WebView2. אם מנגנון הקורא דורש דפדפן חיצוני או הרשאת דפדפן שאינה נתמכת, יש לעבור למעטפת Edge נתמכת במקום לעקוף את מנגנון האבטחה.
4. לבדוק טעינה מוצלחת, טעינה שנכשלה, ביטול תשלום, ניתוק קורא, כרטיס שאינו נתמך, והפעלה מחדש לאחר תקלה.

## אבטחה וגבולות

- האפליקציה אינה אוספת, שומרת או מעבירה פרטי כרטיס אשראי. יש להשאיר את התשלום באתר הרשמי ובספק הסליקה הרשמי בלבד.
- אין להוסיף מארחי תשלום או פרוטוקולים על סמך ניחוש.
- חסימת דומיינים חיצוניים אינה מסירה קישורים או תפריטים פנימיים באתר עצמו. אם עמודי שירות אחרים נמצאים באותו דומיין, מעטפת הדפדפן לבדה אינה יכולה להבטיח שהם יוסתרו או ייחסמו. לשם כך דרוש מסלול טעינה רשמי ייעודי או שיתוף פעולה של מפעיל האתר.
- אין להציג את האפליקציה כמאובטחת לחלוטין או כמאושרת על ידי Rav-Kav Online לפני בדיקות ואישור מתאימים.

## בנייה מקומית

נדרשים Windows 10/11, .NET 10 SDK ו-WebView2 Runtime.

```powershell
dotnet restore .\\RavKavKiosk\\RavKavKiosk.csproj
dotnet build .\\RavKavKiosk\\RavKavKiosk.csproj -c Release
dotnet run --project .\\RavKavKiosk\\RavKavKiosk.csproj
```

## הגדרת מארחים ופרוטוקולים

ערוך את `RavKavKiosk/appsettings.json` רק לאחר אימות בפועל של כתובות היעד ושל פרוטוקול קורא הכרטיסים. השארת הרשימות ללא אימות עדיפה על פתיחת גישה כללית לאינטרנט.
