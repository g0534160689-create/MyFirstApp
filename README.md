# עמדת טעינת רב־קו — Windows

אפליקציית Windows קלה בסגנון עמדת שירות עצמי. מסך הפתיחה מציג הוראות קצרות וכפתור אחד גדול, וממנו נפתח השירות הרשמי של Rav-Kav Online בתוך חלון ייעודי.

## מה יש בגרסה הנוכחית

- מסך פתיחה בעברית, מותאם לעמדת שירות עצמי.
- כפתור יחיד להתחלת תהליך הטעינה.
- רכיב WebView2 נטען רק כאשר המשתמש מתחיל, כדי לצמצם שימוש במשאבים בזמן המתנה.
- אין צורך ליצור חשבון בתוך האפליקציה.
- אין שורת כתובת, לשוניות, תפריטי הקשר או כלי פיתוח.
- חסימת ניווט לכתובות HTTPS שאינן ברשימת האישור, חלונות קופצים והורדות.
- התשלום נשאר באתר ובספק התשלום הרשמיים; האפליקציה אינה אוספת או שומרת פרטי אשראי.

## הורדת גרסת Windows

כל Push ל-`main` מפעיל את GitHub Actions. לאחר הצלחת הבנייה, מורידים את ה-artifact בשם `RavKavKiosk-win-x64` מעמוד Actions:
https://github.com/g0534160689-create/MyFirstApp/actions

החבילה נבנית כיישום self-contained ל-Windows x64, עם קובץ EXE יחיד. נדרש WebView2 Runtime במחשב היעד.

## מה עדיין לא הושלם — חשוב

הגרסה הנוכחית היא מעטפת נוחה לשירות הרשמי, ולא מערכת טעינה עצמאית או מוצר שאושר על ידי מפעיל רב־קו.

- מסך בחירת הסכום אינו מחובר עדיין ל-API רשמי, ולכן בחירת המוצר והסכום נעשית בשירות הרשמי.
- לא אומתה תאימות תהליך קורא הכרטיסים ל-WebView2. פרוטוקולים חיצוניים חסומים כברירת מחדל עד לזיהוי ואימות של פרוטוקול הקורא.
- רשימת המארחים מאשרת כרגע את `ravkavonline.co.il` בלבד. אם האתר מפנה לדומיין תשלום או שירות נוסף, הוא ייחסם עד לאימות והוספה מפורשת.
- חסימת דומיינים אינה מסתירה תפריטים או מסלולים אחרים בתוך אותו אתר. להגבלה מוחלטת לשירות טעינה בלבד נדרש מסלול ייעודי רשמי או שיתוף פעולה של מפעיל האתר.
- לפני שימוש בעמדת טעינה אמיתית נדרשות בדיקות עם קורא USB, כרטיס אמיתי, תשלום ובדיקת הצלחה/כישלון.

## עקרונות אבטחה

- לא עוקפים אימות, סליקה או מנגנוני הגנה של האתר.
- לא שומרים פרטי תשלום.
- לא פותחים גישה כללית לאינטרנט או לפרוטוקולים חיצוניים.
- מוסיפים דומיין או פרוטוקול רק לאחר אימות בתהליך אמיתי.

## פיתוח מקומי

נדרשים Windows 10/11, .NET 10 SDK ו-WebView2 Runtime.

```powershell
dotnet restore .\RavKavKiosk\RavKavKiosk.csproj
dotnet build .\RavKavKiosk\RavKavKiosk.csproj -c Release
dotnet run --project .\RavKavKiosk\RavKavKiosk.csproj
```
