# תמונות למסך הכניסה

יש להוסיף לתיקייה זו את התמונות הבאות כדי להשלים את העיצוב:

- `bg.jpg` — תמונת רקע רחבה של בית מדרש או ספרייה. מומלץ יחס 16:9 וברזולוציה של 1920×1080 לפחות.
- `otzar-logo.png` — לוגו אוצר החכמה, רצוי PNG עם רקע שקוף.

הלוגו הראשי כבר נמצא בתיקייה בשם `daat-logo.png`.

אם אחת התמונות עדיין לא צורפה, התוכנה תעלה עם רקע כהה ועם תווית טקסט במקום לוגו השותף. אין צורך לשנות קוד לאחר הוספת הקבצים; יש לבצע בנייה חדשה של המתקין.
