# תמונות למסך הכניסה

התמונות אינן חייבות להיות ב-GitHub. לאחר התקנת התוכנה, פתחו את תיקיית ההתקנה ואת תיקיית המשנה `Assets` שנמצאת ליד `RavKavKiosk.exe`, והעתיקו אליה ידנית את הקבצים:

- `bg.jpg` — תמונת רקע רחבה של ספרייה או חלל לימוד; מומלץ 1920×1080 או יותר.
- `otzar-logo.png` — לוגו אוצר החכמה, רצוי PNG עם רקע שקוף.
- `daat-logo.png` — הלוגו הראשי של הישיבה (אפשר להחליף את ברירת המחדל).

**אין צורך להעלות את התמונות ל-GitHub, לבנות מחדש או להתקין מחדש.** התוכנה בודקת את תיקיית `Assets` במחשב בכל הפעלה וטוענת את הקבצים לפי שמותיהם. אם קובץ חסר, התוכנה ממשיכה לפעול עם עיצוב חלופי.

המתקין יוצר מראש את תיקיית `Assets` ומאפשר למשתמש להעתיק אליה קבצים גם לאחר ההתקנה.
